# Python Number Guessing Game 🎯

## About
A beginner-friendly number guessing game built using Python. The player tries to guess a randomly generated number.

## Features
- Random number generation
- User input
- Feedback on guesses
- Simple command-line interface

## Requirements
- Python 3 installed

## How to Run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

```bash
python guessing_game.py
```

## Concepts Learned
- Variables and data types
- Conditional statements
- Loops
- User input
- Random number generation
